# negentropy

negentropy applies thermodynamic reasoning to information: it scores systems by how much useful work their information content can perform. Powers Orkid's ZK-gating and route-quality scoring. Ships as a CLI.

## When to use

You need a principled scoring function for noisy signals — proofs, quotes, model outputs — grounded in information theory rather than heuristics.

## Install

```
cargo install orkid-negentropy
```
